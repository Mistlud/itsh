# 이 곡 노래방에 있어? (itsh)

> 곡명 또는 가수명을 검색하면, 금영·TJ 노래방 수록 여부를 즉시 확인해주는 1페이지 반응형 웹앱

🔗 [https://itsh.vercel.app](https://itsh.vercel.app) *(배포 예정)*

---

## 기능

- **곡명 / 가수명 탭** 선택 후 검색
- 입력 1초 후 자동 검색, 엔터/버튼 즉시 검색
- **TJ만 보기 / 금영만 보기** 토글 필터
- **TJ 일본곡만 보기** 토글 (번호 대역 기반 자동 판별)
- 최신순 / 오래된 순 / 곡명순 / 번호순 정렬
- **페이지당 10 / 20 / 50 / 100개** 선택 (기본 20개), 번호 버튼 페이지네이션
- 결과 카드: 브랜드 뱃지, 곡번호, 곡명, 가수명, 출시일

## 기술 스택

- React 19 + Vite 8
- Vanilla CSS (다크 테마, glassmorphism)
- [Manana API](https://api.manana.kr) — 금영·TJ 노래방 데이터

## 로컬 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

## 알려진 제한 사항

- Manana API 데이터 기준이므로, API에 수록되지 않은 곡은 검색되지 않을 수 있음
- TJ 일본곡 판별은 번호 대역 기준 (6100~6999, 25000~29000, 52565~67999, 68000~68999)
- 검색어 공백 처리: 일반 API 호출은 공백 제거, 브랜드 전용 호출은 %20 인코딩 (API 특성)
- 가수명 검색 시 한글/영문 표기가 혼재하는 경우 각각 검색 필요 (예: 아이유 / IU)
